## How to read this library

Each source carries a **verification status**:

- **V1 – Located this session:** the source was found by web search in this session, and its title, authors and key claim were confirmed from the search results. A URL is given.
- **V2 – Bibliographic knowledge:** a well-known publication cited from professional knowledge. It was **not retrieved** in this session. Verify page numbers and wording before quoting it externally.

No benchmark statistic in this project is used as a design input unless it is labelled with its source and status. Saudi legal sources are listed separately in `16_Saudi_Compliance/Phase1_Saudi_Compliance_Review.md`.
