# 🤝 منسق التوظيف: وكيل ذكاء اصطناعي للموارد البشرية

وكيل مبني على Claude يساعد فريق الموارد البشرية في تنسيق التوظيف. تكتب له طلبك بالعربي، ويقرأ البيانات وينفذ المهمة بنفسه.

## وش يقدر يسوي؟

| المهمة | مثال تكتبه |
|---|---|
| عرض المرشحين وحالاتهم | «مين المرشحين الجدد لوظيفة المحاسب؟» |
| مقارنة المرشحين بالمتطلبات | «قارن مرشحي أخصائي الموارد البشرية ورشّح الأنسب» |
| حجز مقابلة | «احجز لنورة مقابلة يوم 12 أكتوبر مع أ. سارة» |
| كتابة إيميل دعوة | تنكتب تلقائياً بعد الحجز |
| إعادة جدولة أو إلغاء | «ألغِ مقابلة نورة، عندها ظرف» |
| تحديث حالة المرشح | «انقل ريم لمرحلة العرض الوظيفي» |
| إيميل اعتذار أو عرض وظيفي | «اكتب اعتذار لعبدالله بأسلوب لطيف» |
| تحديث لمدير التوظيف | «اكتب لخالد ملخص عن مرشحي وظيفته» |

## الأمان

- **الوكيل ما يرسل أي إيميل.** كل الإيميلات تنحفظ كمسودات في مجلد `outbox/` وتراجعها قبل الإرسال.
- يطلب تأكيدك قبل الإجراءات الحساسة، مثل الرفض والعرض الوظيفي والإلغاء.
- يقيّم المرشحين على المؤهلات والخبرة فقط، وما يدخل العمر أو الجنس أو الجنسية في التقييم.

## التشغيل

1. ثبّت Python 3.10 أو أحدث.
2. ثبّت المكتبة:
   ```bash
   pip install -r requirements.txt
   ```
3. خذ مفتاح API من [platform.claude.com](https://platform.claude.com) وحطه في متغير البيئة:
   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```
4. شغّل الوكيل:
   ```bash
   python agent.py
   ```

## الملفات

```
hr-recruiting-agent/
├── agent.py          # الوكيل: التعليمات وحلقة المحادثة
├── tools.py          # الأدوات اللي يستخدمها الوكيل
├── data/
│   ├── jobs.json        # الوظائف الشاغرة
│   ├── candidates.json  # المرشحين
│   └── slots.json       # مواعيد المقابلات المتاحة
└── outbox/           # مسودات الإيميلات (ينشأ تلقائياً)
```

## تخصيصه لشركتك

- **بياناتك:** استبدل محتوى ملفات `data/` ببيانات شركتك وحافظ على نفس الحقول. البيانات الحالية تجريبية.
- **التعليمات:** عدّل `SYSTEM_PROMPT` في `agent.py`، مثل اسم الشركة وأسلوب الإيميلات والتوقيع.
- **ربط مستقبلي:** تقدر تستبدل دوال `tools.py` بربط مع Gmail أو Google Calendar أو نظام ATS، والوكيل نفسه يبقى بدون تغيير.

> ⚠️ لا ترفع بيانات مرشحين حقيقية إلى GitHub، خصوصاً إذا كان المستودع عام.
